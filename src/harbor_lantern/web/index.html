조사된 도시

지명 검색 결과 조사된 가이드가 없는 곳은 제한된 자동 추천으로 만듭니다.

Trip.com 조사 자료를 사용합니다. 추가 API 조회 없이 평가 수를 보정합니다.

리뷰 연결 시 최대 40개 후보를 확인합니다. 미제공·조회 실패 장소는 기존 정보로 계획합니다.

1~14일 · 현지 날짜 기준. 검색한 여행지를 선택해 주세요.

YOUR ITINERARY

핀은 일정 전체, 점선은 선택한 날짜의 방문 순서입니다. 실제 도로 경로는 장소별 길찾기에서 확인하세요. 핀을 누르면 해당 장소로 이동합니다. ‘내 위치’를 누를 때만 위치 권한을 요청합니다.

장소·체류시간·순서·날짜를 바꾸면 이 브라우저의 내 여행에 저장됩니다.

GOOD FOOD, CLOSE BY

지금, 가까운 한 끼

현재 위치 주변 음식점의 거리·영업시간과 제공되는 평점·후기를 확인하세요.

화제의 메뉴부터 분위기 좋은 한 끼까지.
소개 이유와 출처를 확인하며 골라보세요.

위치 버튼을 누르면 브라우저에 권한을 요청합니다. 일반 맛집 검색은 좌표를 장소 제공자에 전송하며, 트렌드 픽의 거리 계산은 이 브라우저에서 처리합니다.

도시를 고르거나 현재 위치로 주변 음식점을 찾아보세요.

데이터와 서비스 안내

계획은 이 브라우저에 저장됩니다. 현재 위치는 맛집 검색 시에만 사용하며 실시간 이동 경로를 기록하지 않습니다. 공개 장소 검색은 Nominatim/Overpass를 사용합니다. Google Maps 데이터가 표시되는 경우 Google 서비스 약관 및 개인정보처리방침이 적용됩니다. 평점과 후기는 제공자의 결과이며 서비스의 보증이 아닙니다.
