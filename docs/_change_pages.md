# Pages + 로컬 API 배포

2026-09-13. 사용자가 Harbor Lantern과 외부 기기 사용, 임시 HTTPS 터널을 지정했다.

화면은 공개 정적 저장소에 배포하고 PC의 FastAPI/SQLite를 HTTPS 터널로 연결한다.
참가자 토큰은 저장소에 포함하지 않는다. DB·실행 로그·실행 파일도 공개하지 않는다.
Pages 출처에 대한 CORS, ETag 노출, API no-store 응답을 적용했다.
일정·경비·날씨·환율 라우터 및 앱 팩토리를 연결하고 체류시간 인자 불일치를 수정했다.

통합 검증은 여행 생성, 초대 참여, 27개 스팟, 토큰 없는 접근 차단,
다른 여행 토큰 차단, ETag 304, 일정 추가·수정·충돌409·완료·삭제,
경로 제안, 경비 기록·조회·삭제, 정산 잔액 합계, CORS 허용·거부를 포함한다.
테스트는 외부 네트워크를 차단하고 가짜 환율 공급자를 사용한다.

운영 제약: PC/백엔드/터널이 실행 중이어야 하며 터널 재시작 시 Pages의 API 주소를 갱신한다.
기존 표준 문서 00/03/04/05는 미완성으로, 전체 프로젝트 문서 게이트 통과를 주장하지 않는다.
