| 종목 | p50 | p95 | p99 | 최대 | 목표 |

## 6. 특기할 검증 (놓치기 쉬운 자리를 실제로 고정했다)

| 검증 | 내용 |
|------|------|
| ETag가 거짓말하지 않는다 | `FixedClock`을 9시간 진행(10:00→19:00 HKT)해도 `/state`의 `json()`·`content`·`ETag`가 **전부 동일**. 본문이 현재시각에 의존하면 304를 받은 클라이언트가 변경을 영영 못 본다 |
| 재정렬 중간 상태 충돌 | 4스팟 일자의 **24개 순열 전부** + 6스팟 회전 6회. 2개짜리로만 봤다면 통과했을 자리 |
| `version` ↔ `expected_revision` | 서로의 자리에 넣으면 각각 409, 서로의 필드명으로 보내면 422 — 양방향 |
| 캐시 single-flight | 스레드 2개가 동시에 만료를 만나도 외부 호출 **1회**(`.calls` 카운터 실측) |
| 가짜 경고 금지 (AC-024) | 시드 27건 중 **6건을 `unknown`으로 남기고 경고를 만들지 않는다.** 무리한 해석은 진짜 경고를 묻는다 |
| 벤더 무결성 | **CRLF 1바이트** 변조·파일 삭제·낯선 파일 추가를 실제로 탐지시켜 확인 |
| 검사기가 정말 실패하는지 | 계층 위반 4종·시크릿 3종을 가짜로 심어 **탐지되는 것을 확인**. 통과만 보는 검사는 검사가 아니다 |
