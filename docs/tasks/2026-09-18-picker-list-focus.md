# 관광지 목록 선택 시 지도 이동

- 장소 목록 클릭 시 선택 좌표로 지도 중심을 이동하고 최소 16단계로 확대한다. 이미 더 확대되어 있으면 유지한다.
- 지도 핀 팝업을 열고 상세 패널을 위로 스크롤한다. 모바일에서 하단 목록을 눌러도 지도 영역이 보이도록 화면을 이동한다.
- 지도 이동에 따른 재조회가 선택을 초기화하지 않도록 현재 영역 안의 선택 장소를 유지한다. 같은 장소의 공급자 ID가 바뀌면 선택 ID도 갱신한다. 사용자가 다른 영역으로 이동하면 영역 밖 선택은 유지하지 않는다.
- 검증: 기존 장소 필터/매칭 테스트 3개, Ruff, diff 검사 통과. 격리된 브라우저에서 데스크톱 1440px·모바일 390px의 중심 좌표·확대·팝업·스크롤 및 빈 부분 응답 이후 선택 유지 확인, JS 오류 없음.
- 프론트엔드만 변경하며 서버 재시작이나 여행 DB 변경은 없다.
