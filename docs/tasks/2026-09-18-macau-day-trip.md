# 10월 홍콩 여행의 마카오 당일치기

사용자 요청: 내 여행의 10월 5–8일 중 하루를 마카오로 구성하고, 추천 이동편의 도착지 기준 지도 동선과 준비물을 제공한다.

## 구현

- 내 여행에 2026-10-05–08 홍콩 여행 대상 적용 UI. 기본 추천일 10월 7일, 다른 날짜 선택 가능.
- 외항 터미널 → 성바울 유적 → 성 도밍고 성당 → 세나도 광장/점심 → 아마 사원 → 외항 터미널. 기존 마카오 가이드의 좌표·설명·평점 출처를 재사용.
- 셩완 08:30 출발 / 외항 17:30 귀환 TurboJET 추천. 입출경 여유, 요금, 여권·통신·현금 등 준비물, 공식 운항·입경 출처를 일정에 표시. 예약을 생성하지 않는다.
- 사용자 브라우저 저장소를 직접 읽거나 수정할 수 없으므로 해당 브라우저에서 적용 버튼을 누르면 선택한 하루만 교체. 원래 하루를 여행 안에 보관하고 복원 가능. 대상 여행이 없으면 명시적으로 마카오 하루만 미리 보거나 저장.
- 장소 추가의 검색 도시를 날짜별로 선택. 마카오 일정 수정 후에도 교통 안내와 원본 백업 유지. 다른 날짜는 재계산 결과로 덮어쓰지 않는다.
- 방문 순서·시간은 기존 편집기를 사용한다. 도보 추정과 참고 지도 선을 실제 페리·택시 경로로 표시하지 않는다.

- https://www2.turbojet.com.hk/notifications/ : 2026-04-25 요금 변경, 평일 주간 HK$194 / 주말·휴일 HK$212 / 야간 HK$242. 옛 사이트 HK$175 요금은 사용하지 않음.
- https://www.gov.mo/en/services/ps-1474/ps-1474b/ : 한국 여권 사증 면제·최대 90일, 체류 종료 후 90일 이상 여권 유효기간. 타 국적과 홍콩 재입경은 별도 확인.
- https://www.macaotourism.gov.mo/en/ : 공식 관광 안내. 장소별 원문은 기존 가이드 출처 유지.

## 검증

- Node 실행 테스트: 다른 날짜 원문 보존, 원본 불변, ID 유지, 적용·복원, 중복 방지, 날짜·요일, 출력 이스케이프.
- 격리된 브라우저에서 실제 API 사용: 적용·원복, 마카오 장소 검색, 시간 변경 후 안내/백업 유지, 재접속, 모바일 가로 넘침 없음, 미리 보기 무저장, JS 오류 없음.
- 사용자 실제 브라우저의 저장 여행을 변경했다고 주장하지 않는다. 배포 후 내 여행의 적용 버튼을 안내한다.
