# SNS·트렌드 맛집 필터

- 요청: 인스타그램이나 요즘 인기 있는 맛집만 골라 보는 기능.
- 구현: 일반 주변 맛집 / SNS·트렌드 픽 선택, SNS 화제·식사·브런치·감성 카페 필터, 도시 전체 / 반경 검색, 지도-목록 동기화, 지도 초점 버튼.
- 자료: 홍콩 8개 지점. Time Out Hong Kong 개별 소개 페이지를 2026-09-19 확인하고 각 페이지 JSON-LD의 지점 주소와 좌표를 사용했다. Milk Bar는 검색엔진 캐시가 2021년 내용을 반환했으나 원문은 2026년 갱신 내용과 바이닐 테마를 확인했다.
- SNS 태그는 Threads 화제가 명시된 Zero One과 Instagram 유입이 명시된 Milk Bar에만 부여했다. 다른 장소는 에디터 소개에 따른 취향 분류다.
- 기사 수정일과 자료 확인일을 별도로 표시한다. 평점, 후기 수, 방문객 연령, 실시간 인기도를 추정하지 않는다. 현재 자료가 없는 지역은 일반 음식점으로 채우지 않는다.
- API·DB·의존성 변경 없음. 정적 Pages 배포만 필요하다.
- 검증: pytest 923개 통과. 브라우저 필터·좌표·모바일 확인 및 배포 결과는 아래에 기록한다.
- 재현: tools/check_trend_food.py (Playwright 선택 설치, CHECK_URL / CHROME_PATH 환경변수). 일반 nearby API는 fixture, 큐레이션은 실제 정적 자료.

- 로컬 검증 완료: 1440px / 390px에서 SNS 2곳, 식사 5곳, 홍콩 전체 8곳, 도쿄 빈 결과, 반경 변경, 내 위치 전환, 지도 핀 동기화·선택 초점, 일반 검색 복귀, 정적 자료 503 안내를 확인했다. 일반 nearby와 위치는 fixture를 사용했다. 페이지 JS 오류·가로 넘침 없음.
- Ruff, 벤더 무결성, 문서 계약 검사 통과. 지도 fitBounds 애니메이션과 선택 초점의 경합을 제거했다.
