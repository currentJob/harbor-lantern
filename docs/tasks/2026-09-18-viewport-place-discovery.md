# 지도 화면 영역 기반 관광지 조회

사용자 요청: 관광지 추가 지도 이동 시 국가·도시 제한 없이 현재 영역의 장소를 조회하고, 평점·리뷰 수·필터·간단 정보·팁을 함께 제공한다.

## 변경

- `GET /api/explore/places/viewport`: Overpass 영역 조회와 전 세계 기존 도시 가이드의 좌표·설명·Trip.com 조사 평점 결합. Wikidata 식별자 또는 동일 이름과 50m 이내 좌표로 연결한다.
- `moveend` 후 700ms 대기, 한 번에 한 요청, 최신 영역만 반영. 결과를 받아 지도를 자동으로 다시 맞추지 않는다. 팝업도 지도 영역을 이동시키지 않는다.
- 종류를 바꾸면 해당 종류로 다시 조회하여 많은 식당 때문에 박물관 등이 잘리는 문제를 줄인다. 최소 별점·리뷰 수·자료·정렬·화면 내 이름 검색은 받은 자료를 필터링한다.
- 공개 지도 설명·영업시간·입장료·접근성·예약 조건을 원문 출처와 함께 표시한다. 자료에 없는 장소별 추천은 만들지 않으며 일반 방문 체크와 구분한다.
- 국가·도시 제한은 없고 날짜변경선도 지원한다. 외부 자원 보호를 위해 좌표 폭 각각 1도 및 약 1,200km² 이내, UI 확대 단계 12 이상에서 조회한다. 공개 지도 500건 제한과 부분 결과를 명시하며 지도 확대를 안내한다.
- 기존 30분·100항목 서버 캐시 재사용. 사용자 화면 조회만 수행하며 Nominatim의 영역 일괄 수집이나 전 세계 선제 다운로드를 하지 않는다.
- 저장된 여행·DB 스키마는 변경하지 않는다. 기존 경로 삽입과 방문 시간·순서 편집을 재사용한다.

## 데이터 한계

OpenStreetMap은 모든 장소의 별점·리뷰를 제공하지 않는다. 현재 131곳의 Trip.com 조사 자료에서
확인되는 평점만 표시한다. 전 세계 장소를 탐색할 수 있다는 것과 전 세계 모든 장소의 리뷰를
제공한다는 것을 구분한다. 미등록 장소, 제공자 장애·조회 상한도 화면에 알린다.

Overpass 영역·공공 서버 자료:
- https://dev.overpass-api.de/overpass-doc/en/full_data/bbox.html
- https://dev.overpass-api.de/overpass-doc/en/preface/commons.html
- https://operations.osmfoundation.org/policies/nominatim/

## 검증

- 전체 테스트 923개 통과. API 계약, 좌표·면적 검증, 날짜변경선, 원문·평점 연결, 캐시·상한·장애, 필터 실행 검증 포함.
- 실제 공급자 조회: 홍콩 초기 영역 475곳, 파리 78곳(평점 연결 4곳), 헬싱키 23곳. 요청 시점·영역에 따라 변동한다.
- 격리된 브라우저: 실제 지도 드래그 후 재조회, 국가 간 이동, 별점/리뷰 수 필터, 늦은 이전 응답 무시, 지도 중심 유지, 일정 추가·저장, 모바일 가로 넘침 없음, JS 오류 없음.
- Ruff·벤더 무결성·문서 계약 통과.
