# 관광 자료를 참고하는 지도 장소 선택

상태: 완료. 기반 9ff8d72. 구현 4b7a1e5.

사용자 요청: Trip.com 또는 별도 여행 관광지 정보를 참고하며 지도에서 선택해 일정에 추가.
기존 실제 검색과 자동 동선 삽입/수동 시각·순서 편집을 유지한다.

구현 범위: 동일한 관광지 선택창에 조사된 도시 관광지와 Trip.com 평점 자료를 핀으로 표시.
실시간 OSM 이름 검색 결과도 같은 지도에 표시. Trip.com 집계/조회일/원문, 관광 설명 출처를
선택 상세에서 확인. 실시간 Trip.com API로 오인시키지 않는다. 기존 연구 자료 재사용,
런타임 MCP 의존성과 유료 API 추가 없음. 모바일/키보드/실패 시 목록 대체 지원.

구현: `place-picker.js`의 네이티브 dialog와 기존 TripMap을 재사용. 숫자 핀과 목록의
번호/선택 상태 동기화, 상세에서 Trip.com 원문 URL의 모든 매개변수 유지. 실제 검색과
기존 자료가 ID/Wikidata 또는 동일 이름+50m 이내로 일치하면 설명/평점 근거를 합친다.
닫기 때 지도와 타이머 참조를 정리하고 늦게 도착한 검색 결과를 무시한다.

검증: pytest 전체 910개, Ruff 통과. Node 병합 검사는 출처 URL/원본 불변과 다른 장소에
평점이 잘못 붙지 않음을 확인. 실제 Chromium 1440/390px에서 프라하 Trip.com 핀 9개,
핀에서 탄치치 둠 선택·평점/원문 확인·자동 삽입·중복 비활성·Prague Zoo 실시간 검색/
핀 선택/추가·평점 URL 저장 및 새로고침 복원을 검증. 지도 라이브러리 미로딩 시에도
목록 선택 가능. 빠른 닫기/재열기 검증 후 JS 오류 0, 모바일 가로 넘침 없음.

배포: Pages 35298455395, CI 35298455390 모두 성공. 공개 사이트의 새 브라우저에서
Trip.com 관광지 핀 선택, 실제 OSM 검색, 일정 삽입, 출처 보존/저장 복원, 모바일과
지도 미로딩 목록 대체를 재확인했다. 서버 코드와 운영 DB 변경 없음.

추가 개선: 지도 숫자 핀 옆에 별점·평가 수를 상시 표시하고, 팝업에도 동일 정보와
평가 출처/조회일을 표시한다. 근거가 없는 값은 '평가 정보 없음'으로 구분한다.
표시 관련 정적 테스트 126개와 Ruff 통과. 실제 프라하 평점 핀 9개/미제공 핀/팝업/
390px 가로 넘침/JS 오류 없음 확인. 이번 변경도 정적 화면만 배포한다.
